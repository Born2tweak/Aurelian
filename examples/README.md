# Examples

Paired bad/good demonstrations of the OS in action. Examples teach faster than theory; each pair shows a realistic artifact twice -- once as commonly produced, once as this OS requires -- with commentary on exactly why the good one is good.

- `planning.md` -- turning an ambiguous request into an executable plan (`../core/03_EXECUTION_ENGINE.md` section 6, Planner skill)
- `refactoring.md` -- behavior-preserving restructuring vs. drive-by rewrite (`../core/03_EXECUTION_ENGINE.md` section 3, `../core/10_TASTE_AND_DESIGN.md` section 3)
- `prompting.md` -- delegating a task to an agent well vs. badly (`../prompts/13_PROMPT_LIBRARY.md`)
- `code-review.md` -- high-signal review vs. "LGTM + nits" (`../core/03_EXECUTION_ENGINE.md` section 7, `../core/08_VERIFICATION_ENGINE.md` section 6)
- `debugging-report.md` -- evidence-grounded fix report vs. fake completion (`../core/03_EXECUTION_ENGINE.md` section 2, `../core/08_VERIFICATION_ENGINE.md` section 5)
