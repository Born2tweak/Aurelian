# Technical Design Spec

## Purpose

Describe the architecture, contracts, and implementation constraints that shape engineering work.

Do not invent facts. Inspect code, configs, tests, and decisions before filling sections.

## Required Sections

### System Overview

High-level components and how they interact.

### Runtime And Tooling

Languages, frameworks, package managers, commands, and environments.

### Data And Contracts

Schemas, APIs, events, jobs, queues, files, and external integrations.

### Architecture Boundaries

What owns what? Which layers may call each other?

### Verification Commands

Setup, test, lint, typecheck, build, format, and release checks. Include evidence that commands were observed when available.

### Known Constraints

Performance, security, deployment, compatibility, migration, or operational constraints.

### Open Technical Questions

Questions whose answers change implementation choices. Link to `07_RESEARCH_GAPS.md` when needed.
