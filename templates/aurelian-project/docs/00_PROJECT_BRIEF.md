# Project Brief

## Purpose

Capture the smallest reliable summary of what this project is, who it serves, and what success means.

Do not invent facts. If a fact is unknown, write `Unknown` and add it to `07_RESEARCH_GAPS.md`.

## Required Sections

### Objective

What outcome should this project produce?

### Audience

Who uses, maintains, operates, or reviews it?

### Current State

What exists today? Link to evidence where possible.

### In Scope

What may change?

### Out Of Scope

What must not change without explicit approval?

### Done Criteria

What observable evidence proves the current project phase is complete?

### Risks

Name correctness, security, data, money, legal, production, public contract, or reputation risks.
