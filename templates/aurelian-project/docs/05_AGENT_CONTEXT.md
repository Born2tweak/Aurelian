# Agent Context

## Purpose

Give agents the minimum project map needed to start useful work without inventing context.

Do not invent facts. Prefer paths, commands, and verified summaries over broad prose.

## Required Sections

### Start Here

Files agents should read first for common task types.

### Repository Map

Important directories, ownership boundaries, generated files, and files that should not be edited.

### Common Commands

Install, run, test, lint, typecheck, build, format, seed, migrate, and reset commands. Mark unverified commands.

### Task Routing

Which docs, modules, tools, or reviewers apply to common tasks.

### Known Hazards

Fragile areas, confusing names, slow tests, flaky checks, irreversible actions, and external side effects.

### Reporting Expectations

What evidence should appear in final reports for this project.
