# Audit Reports

Use this directory for repository, architecture, dependency, security, accessibility, performance, data, and operational audits.

Each audit should state:

- Scope and non-goals.
- Files, systems, or sources inspected.
- Findings ordered by severity or risk.
- Evidence for each finding.
- Recommended next actions.
- What was not checked.

Do not invent facts. Unsupported concerns belong in `docs/07_RESEARCH_GAPS.md` or the audit's open questions, not in findings.
