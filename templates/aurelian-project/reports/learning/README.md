# Learning Reports

Use this directory for retrospectives and durable lessons from incidents, repeated mistakes, failed approaches, review feedback, or completed milestones.

Each learning report should include:

- Trigger: what happened and why it matters.
- Evidence: logs, diffs, tests, reviews, or user feedback.
- Lesson: the future decision that should change.
- Durable update: instruction, doc, test, hook, checklist, ADR, or skill changed.
- Pruning note: any stale rule or assumption removed.

Do not invent facts. Capture only lessons that change future behavior.
