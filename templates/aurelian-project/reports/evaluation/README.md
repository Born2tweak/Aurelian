# Evaluation Reports

Use this directory for project evaluations, milestone scorecards, Aurelian effectiveness reviews, and benchmark reports.

Each evaluation should include:

- Executive summary.
- Overall score from 0-100.
- Category scores for engineering, product, research, execution, model usage, and knowledge quality where applicable.
- Confidence level for every score.
- Evidence references for every finding.
- Strengths, weaknesses, and risks.
- Immediate fixes and long-term improvements.
- Recommended next milestones.
- Trend compared to previous evaluations, or a note that no comparable prior evaluation exists.
- Unverified areas and limitations.

Use Aurelian's scorecards and benchmark protocol:

- `core/16_EVALUATION_ENGINE.md`
- `skills/26_PROJECT_EVALUATION_SKILL.md`
- `evaluation/18_PROJECT_SCORECARD.md`
- `evaluation/19_BENCHMARK_PROTOCOL.md`

Do not invent benchmark numbers. Missing evidence should lower confidence, mark a score `N/A`, or become an explicit open question.
