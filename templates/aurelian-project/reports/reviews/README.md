# Review Reports

Use this directory for code review, design review, security review, product review, and review-swarm synthesis.

Each review should include:

- Stated intent and scope.
- Artifacts reviewed.
- Findings first, ordered by severity.
- File/line/source evidence for each finding.
- Must-fix items separated from considerations.
- Checks not performed and residual risk.

Do not invent facts. Do not forward another agent's claim as accepted unless evidence supports it.
