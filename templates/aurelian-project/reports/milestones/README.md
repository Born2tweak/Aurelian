# Milestone Reports

Use this directory for completion notes at meaningful project checkpoints.

Each milestone report should include:

- Objective and done criteria.
- Changes made or decisions reached.
- Commands, checks, screenshots, or review evidence observed.
- Files and docs updated.
- Residual risks and unverified areas.
- Recommended next milestone.

Do not invent facts. A milestone is complete only to the level supported by current evidence.
